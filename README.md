# CHIC EX

The latest app by EX, with gorgeous women every month.

This repository distributes the standalone Windows app **CHIC EX** (`CHIC EX.exe`) for the HYPERION DIGITAL EX store. Downloads are on the [Releases](https://github.com/Teobokki/chic-ex/releases) page:

- `CHIC-EX-<version>-Windows-x64.zip` — extract and run `CHIC EX/CHIC EX.exe`
- `CHIC.EX.exe` — the standalone app itself

`latest.json` tells HYPERION DIGITAL EX which version is current.
